# Object-oriented design

Design principles, modelling in modern Java, code smells, and low-level design case studies.

Package root: `learn.ood`. Topics and progress: [oo-design.md](../topics/oo-design.md).

Each topic is one package holding its code, its article (`README.md`) and its question log (`NOTES.md`). Start one with `scripts/new-topic.sh oo-design <slug> "Title"`.
