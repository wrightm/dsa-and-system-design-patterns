# Library studies

Source-reading notes on the JDK and open source libraries: what the code does, which decisions it made, and what each one cost. Scaffolded from the library study template.

Package root: `learn.libstudy`. Topics and progress: [library-studies.md](../topics/library-studies.md).

Each topic is one package holding its code, its article (`README.md`) and its question log (`NOTES.md`). Start one with `scripts/new-topic.sh library-studies <slug> "Title"`.
