# Data structures

Structures built from scratch, each compared with the JDK or library version that does the same job.

Package root: `learn.ds`. Topics and progress: [data-structures.md](../topics/data-structures.md).

Each topic is one package holding its code, its article (`README.md`) and its question log (`NOTES.md`). Start one with `scripts/new-topic.sh data-structures <slug> "Title"`.
