# Enterprise integration patterns

The messaging patterns from Hohpe and Woolf, each built in plain Java first and then found in Apache Camel or Spring Integration.

Package root: `learn.eip`. Topics and progress: [enterprise-integration-patterns.md](../topics/enterprise-integration-patterns.md).

Each topic is one package holding its code, its article (`README.md`) and its question log (`NOTES.md`). Start one with `scripts/new-topic.sh enterprise-integration-patterns <slug> "Title"`.
