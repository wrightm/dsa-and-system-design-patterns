# Challenges

Solutions to coding challenges, one package per problem under `learn.challenges`.

Each solution's `README.md` states the problem in its own words, the signal that pointed to the technique, and links to the topic articles it uses. Those articles link back from their "Seen in" line, so the route from problem to pattern is recorded in both directions.

Start one with `scripts/new-topic.sh challenges <slug> "Title"`.
