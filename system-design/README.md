# System design case studies

Worked designs: requirements, estimates, API, data model, the hard parts in depth, and the trade-offs taken. Mostly prose and diagrams, with code where a part is worth building.

Package root: `learn.sysdesign`. Topics and progress: [system-design.md](../topics/system-design.md).

Each topic is one package holding its code, its article (`README.md`) and its question log (`NOTES.md`). Start one with `scripts/new-topic.sh system-design <slug> "Title"`.
