# About

I'm Michael Wright. This site is my working notebook for data structures, algorithms, design patterns and distributed systems, written so that other people can learn from it too.

## How an article is made

1. I meet a topic, usually in a coding challenge or at work.
2. I build the simple version, find where it breaks, and build the real one with tests.
3. I read how the JDK or a well-known library solves the same problem and note where it differs from mine and why.
4. The questions I asked along the way go into the article.

I work through topics with Claude, Anthropic's AI model, as a pair: it helps with drafting, with reading source code, and with checking claims. Every piece of code is compiled and tested in the repository, and every source reference is checked against a pinned release. If you find a mistake, please tell me.

## The code

Everything is in one repository: [wrightm/dsa-and-system-design-patterns](https://github.com/wrightm/dsa-and-system-design-patterns). Each article sits in the same folder as the code it describes. It is MIT licensed.

## Get involved

- Found an error, or something unclear? [Open an issue](https://github.com/wrightm/dsa-and-system-design-patterns/issues).
- Have a question an article did not answer? Open an issue for that too. Good questions get added to the article.
