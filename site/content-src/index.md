# DSA and system design patterns in Java

Data structures, algorithms, design patterns and distributed system patterns. Each one is built from scratch in Java, tested, and then compared with the code that runs in production.

## Why another set of tutorials

Each article here does three things that most skip.

**It starts from the version that fails.** You see the simple approach first, and the exact point where it breaks. The real design then arrives as a fix for a problem you have just watched happen.

**It reads production source.** Every topic is checked against how the JDK or an open source library does it, with links pinned to a release tag, the decisions the authors made, and what each decision cost them.

**It keeps the questions.** The confusions that came up while learning the topic are written down and answered, because the question you are stuck on is probably one of them.

Every claim is backed by a test you can run from the [repository](https://github.com/wrightm/dsa-and-system-design-patterns).
